# VoteWise AI 🗳️

**Mastering Democracy through AI and Interaction**

VoteWise AI is a premium educational platform designed to empower citizens with comprehensive knowledge about the electoral process. Built for the Google Antigravity Challenge, it combines cutting-edge AI, interactive visualizations, and gamified learning to make civic education accessible and engaging.

## ✨ Key Features

- **Interactive Election Timeline**: A 6-stage visual journey through the democratic process, from registration to declaration.
- **Gemini-Powered AI Assistant**: A contextual, neutral chatbot trained to answer complex electoral questions with precision.
- **Interactive Knowledge Quiz**: Test your understanding with real-time scoring and feedback.
- **Educational Guide**: Deep dives into voter rights, identification requirements, and polling procedures.
- **Premium Design**: Sleek dark-mode interface with glassmorphism effects and smooth Framer Motion animations.

## 🛠️ Tech Stack

- **Framework**: React 19 (Vite 8)
- **AI**: Google Generative AI (Gemini 1.5 Flash)
- **Animations**: Framer Motion
- **Icons**: Lucide React
- **Testing**: Vitest + React Testing Library
- **Typography**: Outfit & Inter (Google Fonts)

## 🚀 Getting Started

1. **Clone the repository**
   ```bash
   git clone [repository-url]
   cd Election-Process-Education
   ```

2. **Install dependencies**
   ```bash
   npm install
   ```

3. **Set up API Key**
   - Obtain a Google Gemini API Key from [Google AI Studio](https://aistudio.google.com/app/apikey).
   - Enter it directly into the AI Assistant interface (saved securely in your local storage).

4. **Run development server**
   ```bash
   npm run dev
   ```

5. **Run tests**
   ```bash
   npm test
   ```
