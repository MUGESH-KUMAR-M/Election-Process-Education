# VoteWise AI 🗳️

**Mastering Democracy through AI and Interaction**

VoteWise AI is a premium educational platform designed to empower citizens with comprehensive knowledge about the electoral process. Built for the Google Antigravity Challenge, it demonstrates deep integration with Google Services.

## 🚀 Google Services Adoption (High Adoption Tier)

This project achieves a high level of integration with the Google ecosystem:
- **Google Identity Services**: Integrated "Sign in with Google" (GSI) for professional user authentication and personalization.
- **Google Generative AI (Gemini)**: Deeply integrated as an interactive election assistant with safety protocols.
- **Google Maps Platform**: Integrated polling station locator and commission office mapping.
- **Google Translate**: Built-in multi-language support for global accessibility.
- **Google Calendar**: Native "Save to Calendar" integration for important election dates.
- **YouTube Integration**: Embedded educational video base for multi-modal learning.
- **Google Fonts**: Performance-optimized typography using the Google Fonts API.

## ✨ Key Features

- **Interactive Election Timeline**: A 6-stage visual journey through the democratic process.
- **Gemini-Powered AI Assistant**: Contextual, neutral chatbot trained to answer complex electoral questions.
- **Interactive Knowledge Quiz**: Gamified learning with real-time scoring.
- **Find Center Module**: Google Maps powered polling station locator.

## 🛠️ Tech Stack

- **Framework**: React 19 (Vite 8)
- **AI**: Google Generative AI (Gemini 1.5 Flash)
- **Auth**: Google Identity Services
- **Efficiency**: Component Memoization & Lazy Loading
- **Accessibility**: WCAG 2.1 AA Compliant

## 🧪 Testing

- **Unit Tests**: Critical scoring logic and utility functions.
- **Hook Tests**: Gemini integration and state management.
- **Component Tests**: Interaction flow for the Quiz and Timeline.
